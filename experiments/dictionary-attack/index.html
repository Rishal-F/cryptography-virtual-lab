Dictionary Attack

Simulate a dictionary attack by testing a predefined set of candidate passwords against a stored SHA-256 password hash.

Theory

What is a dictionary attack?

A dictionary attack is a password-guessing technique that tests a prepared list of likely passwords against a protected password representation. Unlike a brute-force attack, which generates every possible combination, a dictionary attack focuses on words and patterns that people commonly choose.

Targeting password hashes

Systems should store password hashes rather than plaintext passwords. A hash is a one-way representation that makes it difficult to recover the original password directly. If an attacker obtains a stored hash, however, they can hash guessed passwords and compare the results with the stolen value.

Dictionary and SHA-256 comparison

This simulation uses a predefined dictionary of commonly used passwords. Each candidate password is processed by the SHA-256 cryptographic hash function. The resulting hash is compared with the target hash stored by the system. Because the same input produces the same SHA-256 output, an equal hash indicates that the candidate matches the password represented by the target hash.

The attack stops as soon as a matching hash is found, avoiding unnecessary tests after success. If none of the dictionary candidates produces the target hash, the attack fails for this dictionary. This does not prove that the password is secure; it means only that the password was not found among the candidates tested.

Algorithm

  1. Obtain the target SHA-256 password hash.
  2. Read the candidate passwords in dictionary order.
  3. Hash the current candidate with SHA-256.
  4. Compare the candidate hash with the target hash.
  5. If the hashes match, report the candidate and stop the attack.
  6. If the dictionary is exhausted without a match, report failure.

Procedure

  1. Open the Simulation tab.
  2. Enter or select a target password for the experiment.
  3. Generate or use its stored SHA-256 hash.
  4. Start the dictionary attack.
  5. Observe each candidate password as it is tested.
  6. Observe the generated hash and its comparison result.
  7. Observe the attack stopping when a matching hash is found.
  8. Observe the failure result when the password is not present in the dictionary.
  9. Reset the simulation to perform another experiment.
